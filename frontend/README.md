# NASA Pakistan Climate Dashboard — Frontend

The main project documentation is available in the repository root [`README.md`](../../README.md).

## Requirements

- Node.js 22.12.0 or newer in the Node 22 line
- npm 10 or newer

The project is compatible with **Node 22.16.0 and npm 10.9.2**. No global version change is required.

## Run

```bash
npm ci
npm start
```

The committed lockfile is registry-neutral and the local `.npmrc` uses the official public npm registry. The Angular application runs at `http://localhost:4200` and expects the ASP.NET Core API at `http://localhost:5016`.
